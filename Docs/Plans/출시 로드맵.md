# Project-SOS 출시 로드맵

> 작성일: 2026-03-22
> 현재 상태: 핵심 RTS 시스템(선택/이동/전투/건설/채집/웨이브/미니맵) 구현 완료

---

## P0: 출시 차단 요소 (없으면 게임이 성립하지 않음)

### 1. 사운드 시스템
- **현재**: 사운드 관련 코드 전무
- **필요 작업**:
  - 사운드 매니저 (DOTS 친화적, Managed → unmanaged 이벤트 브릿지)
  - BGM 재생/전환 (메뉴, 인게임, 웨이브 긴장감 단계별)
  - 효과음: 공격(근접/원거리), 피격, 사망, 건설 시작/완료, 자원 채집, 유닛 생산, 유닛 선택/명령 응답
  - UI 사운드: 버튼 클릭, 메뉴 열기/닫기, 알림
  - 3D Spatial Audio: 카메라 거리 기반 감쇠
- **설계 고려**: ECS 시스템에서 직접 AudioSource 호출 불가 → SoundEvent 버퍼 + MonoBehaviour 브릿지 패턴

### 2. 애니메이션 시스템
- **현재**: `Docs/Plans/Animation` 에 6단계 계획 존재, 미착수
- **필요 작업**:
  - 유닛/적 Idle, Walk, Attack, Death 애니메이션
  - GPU Instanced Animation 또는 Unity DOTS Animation (성능 고려)
  - 건물 건설 진행 시각화 (스케일 업 또는 반투명→불투명)
- **의존성**: 아트 에셋 확보 필요

### 3. 승리/패배 조건 완성
- **현재**: HeroDeath → GameOverRpc 만 존재 (패배만 구현)
- **필요 작업**:
  - 승리 조건 정의: 모든 웨이브 클리어, 또는 보스 처치, 또는 일정 시간 생존
  - `WaveManagerSystem`에 최종 웨이브 완료 판정 추가
  - 승리 시 GameOverRpc 확장 (승/패 구분 필드)
  - 결과 화면 UI (킬 수, 생존 시간, 자원 수집량 등 통계)

### 4. 메인 메뉴 / 게임 진입 UI
- **현재**: InGame 씬 하나, AutoConnect 직접 연결
- **필요 작업**:
  - 타이틀 화면 씬 (게임 시작, 설정, 종료)
  - 싱글플레이/멀티플레이 선택
  - 로딩 화면 (씬 전환, 서브씬 로드 진행률)
  - 게임 내 일시정지/설정 메뉴 (ESC)

## P1: 게임 품질 필수 요소 (없으면 출시 품질 미달)

### 5. HUD 보강
- **현재**: HP 텍스트, 자원 정보, 미니맵, 선택 정보, 토스트 알림
- **추가 필요**:
  - 웨이브 진행 표시 (현재 웨이브, 다음 웨이브 타이머)
  - 생산 큐 진행률 바
  - 킬 카운트 / 스코어보드
  - 유닛 체력바 (월드 스페이스, 현재 적만 있고 아군 없음)
  - 건설 진행률 바
  - 인구수 표시 (현재/최대)

### 6. 핫키 / 컨트롤 그룹
- **현재**: 좌클릭 선택, 우클릭 이동/공격, Q 메뉴 정도
- **추가 필요**:
  - 컨트롤 그룹 (Ctrl+1~9 저장, 1~9 선택, 더블탭 카메라 이동)
  - 전체 유닛 선택 (Ctrl+A 또는 유사)
  - 같은 타입 전체 선택 (더블클릭)
  - 화면 내 유닛 선택
  - A+클릭 (Attack Move)
  - S (Stop), H (Hold Position)

### 7. 파티클 / 시각 이펙트
- **현재**: CommandMarker 페이드만 존재
- **추가 필요**:
  - 공격 이펙트 (근접 타격, 원거리 충돌)
  - 사망 이펙트 (유닛/적/건물)
  - 건설 완료 이펙트
  - 자원 채집 이펙트
  - 투사체 궤적 (현재 `VisualOnlyTag` 투사체는 있으나 trail 없음)

### 8. 밸런싱 / 콘텐츠 확장
- **현재**: 웨이브 3개, 유닛 5종, 적 3종, 건물 3종
- **추가 필요**:
  - 웨이브 최소 10개 이상으로 확장 + 난이도 곡선 설계
  - 적 타입 추가 (탱크형, 스플래시형, 힐러형 등)
  - 유닛/건물 추가 또는 기존 유닛 업그레이드 경로
  - 수치 밸런싱 (DPS, HP, 비용, 생산 시간 스프레드시트)
  - 테크 트리 실제 구현 (`UserTechState` 활용)

### 9. 설정 화면
- **현재**: 없음
- **추가 필요**:
  - 해상도 / 화면 모드 (전체화면, 창모드, 보더리스)
  - 그래픽 품질 단계
  - 사운드 볼륨 (마스터, BGM, 효과음)
  - 키 바인딩 변경
  - 카메라 스크롤 속도

## P2: 경쟁력 확보 요소 (출시 가능하지만 있으면 품질 상승)

### 10. 튜토리얼
- 기본 조작법 안내 (이동, 공격, 건설, 채집)
- 단계별 미션 또는 툴팁 기반
- 첫 플레이 시 자동 진입

### 11. Fog of War
- `VisionRange` 컴포넌트는 이미 존재
- 타일/텍스처 기반 시야 시스템
- 탐사되지 않은 영역 어둡게 처리
- 시야 밖 적 유닛 숨김

### 12. FlowField 길찾기
- `Docs/Plans/FlowField` 에 7단계 계획 존재
- 대량 유닛(50+) 시 NavMesh 기반 PathfindingSystem 병목 예상
- 유닛 수 상한이 낮다면 P3로 내릴 수 있음

### 13. 유닛 AI 고도화
- 순찰 (Patrol)
- 홀드 포지션 (Hold)
- 어택 무브 (Attack Move) -- 핫키와 연동
- 진형 (Formation) 이동
- 자동 수리 / 자동 채집 행동 트리

### 14. 미니맵 상호작용
- 미니맵 클릭으로 카메라 이동
- 미니맵 우클릭으로 이동 명령
- 미니맵에 핑/마커 (멀티플레이어 소통)
