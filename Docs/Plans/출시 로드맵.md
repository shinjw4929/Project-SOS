# Project-SOS 출시 로드맵

> 작성일: 2026-03-22 / 갱신일: 2026-04-05
> 현재 상태: 핵심 RTS + 애니메이션 + 사운드 + FlowField + 룸 서버 + 채팅 구현 완료

---

## P0: 출시 차단 요소 (없으면 게임이 성립하지 않음)

### 1. ~~사운드 시스템~~ ✅ 구현 완료
- **구현 완료**: SoundEvent 버퍼(ECS) → SoundManager(MonoBehaviour) 브릿지 패턴
- `SoundEventEmitSystem`이 상태 변화 감지 → 버퍼 추가, `SoundManager`가 매 프레임 소비
- **남은 작업**:
  - BGM 재생/전환 (메뉴, 인게임, 웨이브 긴장감 단계별)
  - UI 사운드: 버튼 클릭, 메뉴 열기/닫기, 알림
  - 3D Spatial Audio: 카메라 거리 기반 감쇠
  - 효과음 에셋 확충

### 2. ~~애니메이션 시스템~~ ✅ 구현 완료
- **구현 완료**: VAT(Vertex Animation Texture) 방식, Hero/EnemySmall/EnemyFlying 3종 적용
- `VATAnimationAuthoring`(Composition 패턴) + `VATAnimationStateUpdateSystem`(상태→클립 매핑)
- `EntityTiltSystem`으로 전투/사망 기울임 연출 (PostTransformMatrix 기반)
- `ServerDeathSystem` + `DeathTimer`로 사망 연출 후 파괴
- **남은 작업**:
  - 나머지 유닛/적 타입 VAT 에셋 추가
  - 건물 건설 진행 시각화

### 3. 승리/패배 조건 완성
- **현재**: HeroDeath → GameOverRpc 만 존재 (패배만 구현)
- **필요 작업**:
  - 승리 조건 정의: 모든 웨이브 클리어, 또는 보스 처치, 또는 일정 시간 생존
  - `WaveManagerSystem`에 최종 웨이브 완료 판정 추가
  - 승리 시 GameOverRpc 확장 (승/패 구분 필드)
  - 결과 화면 UI (킬 수, 생존 시간, 자원 수집량 등 통계)

### 4. 메인 메뉴 / 게임 진입 UI — 부분 구현
- **구현 완료**: RoomClient 기반 로비/대기실/게임 진입 흐름 (TCP :8080), Netcode 수동 연결 + 토큰 검증
- **남은 작업**:
  - 타이틀 화면 씬 (게임 시작, 설정, 종료)
  - 싱글플레이/멀티플레이 선택
  - 로딩 화면 (씬 전환, 서브씬 로드 진행률)
  - 게임 내 일시정지/설정 메뉴 (ESC)

## P1: 게임 품질 필수 요소 (없으면 출시 품질 미달)

### 5. HUD 보강
- **현재**: HP 텍스트, 자원 정보, 미니맵, 선택 정보, 토스트 알림
- **추가 필요**:
  - 웨이브 진행 표시 (현재 웨이브, 다음 웨이브 타이머)
  - 생산 큐 진행률 바
  - 킬 카운트 / 스코어보드
  - 유닛 체력바 (월드 스페이스, 현재 적만 있고 아군 없음)
  - 건설 진행률 바
  - 인구수 표시 (현재/최대)

### 6. 핫키 / 컨트롤 그룹
- **현재**: 좌클릭 선택, 우클릭 이동/공격, Q 메뉴 정도
- **추가 필요**:
  - 컨트롤 그룹 (Ctrl+1~9 저장, 1~9 선택, 더블탭 카메라 이동)
  - 전체 유닛 선택 (Ctrl+A 또는 유사)
  - 같은 타입 전체 선택 (더블클릭)
  - 화면 내 유닛 선택
  - A+클릭 (Attack Move)
  - S (Stop), H (Hold Position)

### 7. 파티클 / 시각 이펙트
- **현재**: CommandMarker 페이드만 존재
- **추가 필요**:
  - 공격 이펙트 (근접 타격, 원거리 충돌)
  - 사망 이펙트 (유닛/적/건물)
  - 건설 완료 이펙트
  - 자원 채집 이펙트
  - 투사체 궤적 (현재 `VisualOnlyTag` 투사체는 있으나 trail 없음)

### 8. 밸런싱 / 콘텐츠 확장
- **현재**: 웨이브 3개, 유닛 5종, 적 3종, 건물 3종
- **추가 필요**:
  - 웨이브 최소 10개 이상으로 확장 + 난이도 곡선 설계
  - 적 타입 추가 (탱크형, 스플래시형, 힐러형 등)
  - 유닛/건물 추가 또는 기존 유닛 업그레이드 경로
  - 수치 밸런싱 (DPS, HP, 비용, 생산 시간 스프레드시트)
  - 테크 트리 실제 구현 (`UserTechState` 활용)

### 9. 설정 화면
- **현재**: 없음
- **추가 필요**:
  - 해상도 / 화면 모드 (전체화면, 창모드, 보더리스)
  - 그래픽 품질 단계
  - 사운드 볼륨 (마스터, BGM, 효과음)
  - 키 바인딩 변경
  - 카메라 스크롤 속도

## P2: 경쟁력 확보 요소 (출시 가능하지만 있으면 품질 상승)

### 10. 튜토리얼
- 기본 조작법 안내 (이동, 공격, 건설, 채집)
- 단계별 미션 또는 툴팁 기반
- 첫 플레이 시 자동 진입

### 11. Fog of War
- `VisionRange` 컴포넌트는 이미 존재
- 타일/텍스처 기반 시야 시스템
- 탐사되지 않은 영역 어둡게 처리
- 시야 밖 적 유닛 숨김

### 12. ~~FlowField 길찾기~~ ✅ 구현 완료
- NavMesh → FlowField 전환 완료 (Cost Field → Integration Field → Flow Field)
- 관련 완료 계획: FlowField, MovementOverhaul, ArrivalFix, FormationFix, PartialPathRefactor

### 13. 유닛 AI 고도화
- 순찰 (Patrol)
- 홀드 포지션 (Hold)
- 어택 무브 (Attack Move) -- 핫키와 연동
- 진형 (Formation) 이동
- 자동 수리 / 자동 채집 행동 트리

### 14. 미니맵 상호작용 — 부분 구현
- **구현 완료**: 미니맵 좌클릭 드래그 카메라 이동, 뷰포트 표시
- **남은 작업**:
  - 미니맵 우클릭으로 이동 명령
  - 미니맵에 핑/마커 (멀티플레이어 소통)

## P3: 멀티플레이어 인프라 (온라인 출시 시 필수)

### 15. ~~로비 / 매칭 시스템~~ ✅ 구현 완료
- RoomClient(TCP :8080) + RoomUIController: 방 생성/참가/목록/대기실/준비/게임 시작
- 토큰 검증(TokenValidationSystem) + 슬롯 관리(SlotNotifySystem)
- **남은 작업**: 매치메이킹 (ELO 또는 단순 큐), 팀 배정

### 16. ~~채팅 시스템~~ ✅ 구현 완료
- ChatClient(TCP :8082) + ChatUIController: 룸 채팅(LOBBY) / 인게임 전체 채팅(ALL)
- 세션 재인증(ECS 폴링), 패널 위치·크기 룸/인게임 전환, IsChatFocused 입력 격리
- **남은 작업**: 귓속말(WHISPER) 채널

### 17. 재접속 / 연결 안정성 — 부분 구현
- **구현 완료**: RoomClient/ChatClient 자동 재접속 (지수 백오프), 예기치 않은 끊김 시 3초 후 재연결
- **남은 작업**:
  - 일시적 끊김 시 게임 상태 보존
  - 타임아웃 시 AI 대체 또는 유닛 대기

### 18. 서버 인프라
- 전용 서버 빌드 파이프라인 (headless)
- 서버 호스팅 (클라우드 또는 커뮤니티 서버)
- RPC 유효성 검증 강화 (rate limiting, 범위 체크)
- 서버 로그 수집 / 모니터링
