## 1. VAT 셰이더 Emission 지원 추가

**상태**: 완료
**우선순위**: 낮음 (시각 품질 개선)

### 문제

Ghost 적(EnemySmall/EnemyFlying)의 원본 머티리얼(`MaterialGhost.mat`)은 커스텀 셰이더를 사용하여 형광/그라데이션 효과를 구현한다. 현재 VAT 셰이더(`Custom/VATAnimation`)는 기본 PBR만 지원하므로 해당 효과를 재현할 수 없다.

### 원본 셰이더 특수 프로퍼티

| 프로퍼티 | 값 | 용도 |
|----------|-----|------|
| `_MainColor` | `(0.78, 0.29, 1.0, 0)` | 주 색상 (밝은 보라, alpha=0) |
| `_Color` | `(0.65, 0, 0.71, 1)` | 보조 색상 (진한 보라) |
| `_DissolveColor` | `(0.92, 0.52, 1.0, 0)` | Dissolve 효과 색상 |
| `_MainTexture` | `texture_ghost.png` | 메인 텍스처 (비표준 프로퍼티명) |
| `_NoiseScale` | `70` | Noise 기반 그라데이션 |

### 구현 방안

**최소 구현 (Emission)**:
- `VATAnimation.shader`에 `_EmissionColor`, `_EmissionMap` 프로퍼티 추가
- Fragment 셰이더에서 `surfaceData.emission` 설정
- DOTS Instancing에 `_EmissionColor` 등록
- Ghost VAT 머티리얼에 Emission 값 적용 → 형광 느낌 근사

**완전 재현 (커스텀 블렌딩)**:
- 멀티컬러 블렌딩 로직 (MainColor + Color + DissolveColor)
- Noise 기반 그라데이션 패턴
- 원본 셰이더 분석 후 VAT 셰이더에 통합 필요

### 관련 파일

- `Assets/Shaders/VATAnimation.shader`
- `Assets/Download/GhostCharacter_Free/Materials/MaterialGhost.mat`
- `Assets/Download/GhostCharacter_Free/Textures/texture_ghost.png`

## 2. VAT 셰이더 Alpha Cutout 지원

**상태**: 완료
**우선순위**: 중간 (Ghost 적 시각 품질)

### 문제

현재 VAT 셰이더는 Opaque 렌더링만 지원한다. `Base Color`의 alpha 값이 설정되어도 투명도가 반영되지 않는다. Ghost 적의 원본 셰이더는 alpha를 활용한 반투명/페이드 효과를 사용한다.

### 현재 상태

```hlsl
"RenderType" = "Opaque"
"Queue" = "Geometry"
// Blend 모드 없음
```

`surfaceData.alpha = color.a`로 alpha 값을 SurfaceData에 전달하지만, Opaque 렌더링이라 무시됨.

### 구현 방안

**방법 A: Transparent 서브셰이더 추가**:
- 기존 Opaque SubShader 유지 (일반 유닛용)
- Transparent SubShader 추가: `"RenderType" = "Transparent"`, `"Queue" = "Transparent"`, `Blend SrcAlpha OneMinusSrcAlpha`, `ZWrite Off`
- 머티리얼별로 선택 가능하도록 `_Surface` float 프로퍼티 (0=Opaque, 1=Transparent)

**방법 B: Alpha Cutout (Cutoff)**:
- `_Cutoff` 프로퍼티 추가
- Fragment에서 `clip(color.a - _Cutoff)` 처리
- Transparent보다 성능 우수 (정렬 불필요)
- 반투명은 불가, 완전 투명/완전 불투명만 가능

**방법 C: 머티리얼 키워드 분기**:
- `#pragma shader_feature _ALPHATEST_ON _ALPHABLEND_ON` 추가
- 키워드별로 Opaque/Cutout/Transparent 분기

### 성능 고려사항

- Transparent 렌더링은 정렬 비용 발생 → 수천 유닛에서 성능 영향 가능
- Alpha Cutout(방법 B)이 RTS 대규모 환경에 더 적합
- Ghost 적만 반투명이 필요하므로 영향 범위 제한적

### 관련 파일

- `Assets/Shaders/VATAnimation.shader`

## 3. VATBakeUtility 텍스처 자동 복사 한계

**상태**: 인지
**우선순위**: 낮음

### 문제

원본 FBX 머티리얼이 비표준 프로퍼티명(`_MainTexture` 등)이나 커스텀 셰이더를 사용하는 경우, VAT 베이킹 시 텍스처/색상 자동 복사가 불완전할 수 있다.

### 현재 대응

- `_BaseMap` → `_MainTex` → 셰이더 프로퍼티 전체 탐색 순서로 텍스처 탐색
- `_BaseColor` → `_Color` 순서로 색상 탐색
- FBX 에셋 내 Material sub-assets까지 탐색

### 한계

- 커스텀 셰이더의 색상 프로퍼티(`_MainColor` 등)는 자동 복사 안 됨
- 멀티컬러 블렌딩 정보 손실
- 수동 보정 필요한 경우 Console 경고 출력

## 4. Hero UnitActionState가 이동 시 Moving으로 전환되지 않음

**상태**: 완료
**우선순위**: 높음 (Hero 걷기 애니메이션 미재생 원인)

### 문제

Hero에게 이동 명령을 내려도 `UnitActionState.State`가 `Idle(0)`으로 유지되어, VATAnimationStateUpdateSystem이 Walk 클립(인덱스 1)으로 전환하지 않는다. VAT 시스템 자체는 정상 (Idle 애니메이션은 재생됨).

### 원인

`HandleMoveRequestSystem`이 `UnitIntentState = Intent.Move`만 설정하고 `UnitActionState = Action.Moving`은 설정하지 않았음. `MovementArrivalSystem`도 도착 시 `Intent.Idle`만 설정하고 `Action.Idle`은 설정하지 않았음.

### 해결

- `HandleMoveRequestSystem`: 이동 명령 수신 시 `UnitActionState.State = Action.Moving` 설정 추가
- `MovementArrivalSystem`: `Intent.Move` 도착 시 `UnitActionState.State = Action.Idle` 설정 추가

### 관련 파일

- `Assets/Scripts/Server/Systems/Commands/Movement/HandleMoveRequestSystem.cs`
- `Assets/Scripts/Server/Systems/Movement/MovementArrivalSystem.cs`

## 5. Ghost 적 공격 애니메이션 타이밍 불일치

**상태**: 미착수
**우선순위**: 중간 (시각 품질)

### 문제

EnemySmall/EnemyFlying의 `ghost_attack` 클립 재생 시간과 실제 공격 쿨타임이 맞지 않아 모션이 부자연스러움. 클립이 쿨타임보다 짧으면 마지막 프레임에서 정지, 길면 공격 종료 후에도 애니메이션 진행 중.

### 해결 방안

**방법 A: ClipData Fps 조절 (베이킹 불필요)**
- `EnemySmall_ClipData.asset` Inspector에서 `ghost_attack` 클립의 Fps 값 조절
- 공격 쿨타임에 맞춰 재생 속도 조정 (Fps 올리면 빠르게, 내리면 느리게)

**방법 B: 매 공격마다 AnimStartTime 리셋 (코드)**
- 현재: Attacking 상태 진입 시 1회만 AnimStartTime 갱신 (이전 클립과 다를 때만)
- 개선: 서버에서 공격 발동마다 AnimStartTime을 현재 ElapsedTime으로 리셋
- VATAnimationStateUpdateSystem에서 공격 쿨타임 이벤트를 감지하거나, 별도 트리거 필요

### 관련 파일

- `Assets/VATData/EnemySmall/EnemySmall_ClipData.asset` (Inspector Fps 조절)
- `Assets/Scripts/Server/Systems/Animation/VATAnimationStateUpdateSystem.cs`

## 6. ClientDeathSystem과 사망 애니메이션 충돌

**상태**: 인지
**우선순위**: 중간 (사망 연출 필요 시)

### 문제

Hero의 사망 애니메이션(Sleep02, 클립 인덱스 3)과 Ghost 적의 사망 애니메이션(ghost_dissolve, 클립 인덱스 3)이 서버 매핑에 등록되어 있으나, `ClientDeathSystem`이 체력 0에서 `DisableRendering`을 즉시 추가하여 사망 애니메이션이 보이지 않을 수 있다.

### 구현 방안

- `ClientDeathSystem`에 사망 애니메이션 재생 딜레이 추가 (예: 1~2초 후 DisableRendering)
- 또는 Death 상태 진입 시 타이머 컴포넌트 부착 → 타이머 만료 후 렌더링 비활성화
- Ghost dissolve 클립은 Loop=OFF이므로 마지막 프레임에서 정지

### 관련 파일

- `Assets/Scripts/Client/Systems/ClientDeathSystem.cs` (기존)
- `Assets/Scripts/Server/Systems/Animation/VATAnimationStateUpdateSystem.cs`
