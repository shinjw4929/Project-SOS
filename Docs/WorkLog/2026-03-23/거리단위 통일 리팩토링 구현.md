## 핵심 설계 결정

1. **그리드 단일 소스**: StructureFootprint의 Width/Length가 건물 크기의 유일한 정의. PathWidth, WorldWidth 등 모든 파생값은 시스템에서 인라인 계산.
2. **CellSize 1.0m**: Width=셀수=미터수로 직관적. FlowField BFS 4배 빠름 (40,000→10,000 셀).
3. **Physics 의존 최소화**: 벽 충돌을 Grid 기반으로 전환하여 경로탐색과 충돌 판정이 동일 소스 사용.
4. **Collider = raycast + 투사체 전용**: 물리 충돌에 Collider 사용 금지 규칙 확립.
