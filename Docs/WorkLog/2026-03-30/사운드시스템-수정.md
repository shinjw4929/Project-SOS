# 사운드 시스템 수정 (적 공격 분리 + 반복 재생 + 사망 상태 + 스폰)

## 수정한 문제

### 1. 공격 사운드가 반복되지 않음
- **원인**: `SoundEventEmitSystem`이 상태 **변화**만 감지. `Attacking` 상태 진입 시 1회만 발생하고, 유지 중 반복 공격에 대한 트리거 없음
- **수정**: `CombatStats.AttackSpeed` 기반 타이머 도입. `Attacking` 진입 시 첫 사운드 발생 + 타이머 초기화, 이후 `1/AttackSpeed` 간격으로 반복 재생
- **변경 파일**: `SoundEventEmitSystem.cs`, `PreviousActionState.cs`, `PreviousEnemyContext.cs`

### 2. 적 사운드가 전혀 재생되지 않음
- **원인**: `EnemyState`에 `[GhostComponent]`/`[GhostField]` 없음 → 클라이언트에 값이 복제되지 않아 상태 변화 감지 불가
- **수정**: `EnemyState.CurrentState`에 `[GhostComponent]` + `[GhostField]` 추가
- **변경 파일**: `EnemyState.cs`

### 3. 유닛/적 사망 사운드가 재생되지 않음
- **원인**: `Action.Dying`/`EnemyContext.Dying` enum 값이 존재하지만 **설정하는 코드가 없음**. `ServerDeathSystem`이 `Health <= 0` 감지 시 `Dying` 상태 설정 없이 즉시 엔티티 파괴
- **수정**: `ServerDeathSystem`을 2단계 사망으로 변경
  - 1프레임: `Health <= 0` → `Dying` 상태 설정 + 인구 반환 (Ghost 스냅샷에 Dying 포함)
  - 2프레임: `Dying` 상태 확인 → 엔티티 파괴
- **변경 파일**: `ServerDeathSystem.cs`

### 4. 적 공격 사운드가 아군과 동일
- **수정**: `SoundType`에 `EnemyMeleeHit = 14`, `EnemyRangedShot = 15` 추가. `GetEnemySoundType`에서 적 전용 사운드 반환
- **변경 파일**: `SoundType.cs`, `SoundEventEmitSystem.cs`, `SoundManager.cs`

### 5. 유닛 스폰 사운드 추가
- **수정**: `SoundType.UnitSpawn = 25` 추가. `SoundEventEmitSystem.InitializePreviousStates`에서 `PreviousActionState` 미부착 유닛 감지 시 스폰 사운드 발생
- **변경 파일**: `SoundType.cs`, `SoundEventEmitSystem.cs`, `SoundManager.cs`
