# 룸 서버 연동

## 전체 흐름

```
[앱 시작]
  RoomClient (MonoBehaviour, DontDestroyOnLoad)
  └─ ConnectToRoomServer("127.0.0.1", 8080)
     ├─ TCP 연결 (TcpClient, async/await)
     ├─ 3회 지수 백오프 재시도 (1s, 2s, 4s)
     └─ 성공 → State: Lobby

[로비]
  RoomClient.SendRoomListRequest() → RoomListResponse → UI 갱신
  RoomClient.SendCreateRoom() → CreateRoomResponse → State: InRoom
  RoomClient.SendJoinRoom() → JoinRoomResponse → State: InRoom

[대기실]
  RoomClient: RoomUpdate 수신 → UI 갱신 (유저 목록, 준비 상태)
  RoomClient.SendToggleReady()
  RoomClient.SendStartGame() (호스트 전용)

[GameStart 수신]
  RoomClient.HandleGameStart()
  ├─ State: Matched
  ├─ WriteRoomAuthState() → RoomAuthState 싱글톤에 AuthToken + SessionId 기록
  ├─ NetcodeConnectionUtil.Connect(clientWorld, host, port) → Netcode 수동 연결
  └─ State: InGame

[게임 서버 접속]
  GoInGameClientSystem
  ├─ RoomAuthState.AuthToken.Length == 0 → return (토큰 없으면 대기)
  ├─ AuthToken 포함하여 GoInGameRequestRpc 전송
  └─ NetworkStreamInGame 부착

[토큰 검증 (서버)]
  TokenValidationSystem (UpdateBefore: GoInGameServerSystem)
  ├─ GoInGameRequestRpc.AuthToken → RoomTokenValidator.Validate() (TCP :8081)
  ├─ 유효 → TokenValidatedTag + RoomSessionInfo 부착
  └─ 무효 → NetworkStreamRequestDisconnect + RPC 파괴

[게임 진입 (서버)]
  GoInGameServerSystem
  └─ WithAll<GoInGameRequestRpc, TokenValidatedTag> → Hero 생성

[세션 관리 (서버)]
  SlotNotifySystem
  ├─ ConnectionState.Disconnected 감지 → SlotReleased 전송 (TCP :8081)
  └─ 30초마다 GameServerHeartbeat 전송
```

## 클라이언트 구성 요소

### RoomClient (MonoBehaviour)

| 항목 | 내용 |
|------|------|
| 파일 | `Client/Network/RoomClient.cs` |
| 생명주기 | DontDestroyOnLoad, Application.quitting 정리 |
| 통신 | System.Net.Sockets.TcpClient, async/await |
| 프로토콜 | Protobuf Envelope + 4byte LE length-prefix |
| 프레이밍 | `ProtobufFraming.Frame()` / `TryDeframe()` (Shared) |

#### 상태 머신

```
Disconnected → Connecting → Lobby → InRoom → Matched → InGame
     ↑                        ↑        │                  │
     │                        │  Reject(RoomClosed)        │
     │                        └────────┘                   │
     └──────────── OnGameOver / ReturnToLobby ─────────────┘
```

| 상태 | 진입 조건 | 허용 동작 |
|------|-----------|-----------|
| Disconnected | 초기 상태, 연결 끊김 | ConnectToRoomServer |
| Connecting | ConnectToRoomServer 호출 | (대기) |
| Lobby | TCP 연결 성공 | RoomList, CreateRoom, JoinRoom |
| InRoom | CreateRoom/JoinRoom 성공 | ToggleReady, StartGame, LeaveRoom |
| Matched | GameStart 수신 | (Netcode 연결 대기) |
| InGame | Netcode 연결 성공 | OnGameOver, ReturnToLobby |

#### 이벤트

```csharp
event Action<RoomInfo> OnRoomCreated;
event Action<RoomInfo> OnRoomJoined;
event Action<RoomListResponse> OnRoomListReceived;
event Action<RoomInfo> OnRoomUpdated;
event Action<GameStart> OnGameStartReceived;
event Action<RejectResponse> OnRejected;
event Action<string> OnError;
event Action<RoomClientState> OnStateChanged;
```

#### 에러 처리

| 시나리오 | 처리 |
|---------|------|
| 접속 실패 | 3회 지수 백오프 재시도 → 실패 시 OnError |
| Lobby/InRoom 중 연결 끊김 | 자동 재접속 시도 |
| Reject(RoomClosed) 수신 | HandleReject → State: Lobby 전환 → 방 목록 자동 재요청 |
| GameStart 후 게임 서버 접속 실패 | OnError → 로비 복귀 가능 |
| 토큰 만료 (60초 TTL) | 서버 측 검증 실패 → Disconnect → 자동 재접속 |

### RoomAuthState (ECS 싱글톤)

| 항목 | 내용 |
|------|------|
| 파일 | `Client/Component/Singleton/RoomAuthState.cs` |
| 초기화 | ClientBootstrapSystem (기존 싱글톤 패턴) |
| 용도 | RoomClient(MonoBehaviour) → GoInGameClientSystem(ECS) 토큰 전달 브릿지 |

```csharp
public struct RoomAuthState : IComponentData
{
    public FixedString128Bytes AuthToken;   // Length == 0이면 미발급
    public FixedString128Bytes SessionId;
}
```

### NetcodeConnectionUtil (static)

| 항목 | 내용 |
|------|------|
| 파일 | `Client/Network/NetcodeConnectionUtil.cs` |

### RoomUIController (MonoBehaviour)

| 항목 | 내용 |
|------|------|
| 파일 | `Client/Controller/UI/RoomUIController.cs` |
| 용도 | RoomClient 이벤트 구독 → 상태별 패널 전환 + UI 갱신 |

패널 구성:
- **ConnectingPanel**: 연결 중 스피너
- **LobbyPanel**: 방 목록, 방 생성, 새로고침
- **RoomPanel**: 유저 목록, 준비(비호스트)/시작(호스트)/퇴장 버튼
- **GameStartingPanel**: 게임 서버 접속 중
- **ErrorPanel**: 에러 메시지 + 재시도

## ECS 연동 흐름 (MonoBehaviour → ECS)

```
RoomClient.HandleGameStart()
  │
  ├─ FindClientWorld()     ← World.All에서 world.IsClient()로 탐색
  │
  ├─ WriteRoomAuthState()  ← EntityManager.SetComponentData<RoomAuthState>
  │     AuthToken = new FixedString128Bytes(gameStart.AuthToken)
  │     SessionId = new FixedString128Bytes(gameStart.SessionId)
  │
  └─ NetcodeConnectionUtil.Connect(clientWorld, host, port)
       └─ NetworkStreamDriver.Connect(endpoint)

GoInGameClientSystem.OnUpdate()  [다음 프레임]
  │
  ├─ TryGetSingleton<RoomAuthState>() → AuthToken.Length == 0이면 return
  │
  └─ GoInGameRequestRpc { AuthToken = authState.AuthToken } + SendRpcCommandRequest
```

| 항목 | 내용 |
|------|------|
| Proto 파일 | `Project-SOS-Backend/proto/room.proto` |

### Envelope 메시지 구조

Client → Room Server (:8080):
`CreateRoomRequest`, `JoinRoomRequest`, `LeaveRoomRequest`, `ToggleReadyRequest`, `StartGameRequest`, `RoomListRequest`, `RoomHeartbeat`

Room Server → Client:
`CreateRoomResponse`, `JoinRoomResponse`, `RoomListResponse`, `RoomUpdate`, `GameStart`, `RejectResponse`

Game Server → Room Server (:8081, 내부 채널):
`TokenValidateRequest/Response`, `SlotReleased`, `GameServerHeartbeat`

## TCP 연결 구조

```
클라이언트 (Unity)                     룸 서버 (C++)
─────────────────                     ──────────────
RoomClient ──── TCP :8080 ────────→  Public 채널
  (Envelope 송수신, Heartbeat 10초)

게임 서버 (Unity)                     룸 서버 (C++)
─────────────────                     ──────────────
RoomTokenValidator ── TCP :8081 ──→  Internal 채널 (요청-응답)
SlotNotifyClient ──── TCP :8081 ──→  Internal 채널 (일방향)
  (SlotReleased, Heartbeat 30초)
```
