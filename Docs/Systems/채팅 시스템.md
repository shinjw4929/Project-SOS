# 채팅 시스템

## 개요

C++ 채팅 서버(TCP :8082)와 Unity 클라이언트 간 실시간 텍스트 채팅. MonoBehaviour 기반 TCP 클라이언트 + UI 컨트롤러 구조.

---

## 구성 요소

| 파일 | 어셈블리 | 역할 |
|------|---------|------|
| `Client/Network/ChatClient.cs` | Client | 채팅 서버 TCP 연결, 인증, 메시지 송수신 |
| `Client/Controller/UI/ChatUIController.cs` | Client | 채팅 UI 표시, 입력 처리, 키보드 가드 |
| `Shared/Network/ProtobufFraming.cs` | Shared | 제네릭 4byte LE length-prefix 프레이밍 (Room/Chat 공용) |
| `Shared/Network/Generated/Chat.cs` | Shared | protoc 생성 코드 (Sos.Chat 네임스페이스) |

---

## 프로토콜

| 항목 | 내용 |
|------|------|
| Proto 소스 | `Project-SOS-Backend/proto/chat.proto` |
| 네임스페이스 | `Sos.Chat` |
| 프레이밍 | 4byte little-endian length prefix + ChatEnvelope protobuf |
| 최대 메시지 크기 | 200 bytes (UTF-8) |

### 채널

| 채널 | 값 | 용도 |
|------|---|------|
| CHANNEL_LOBBY | 1 | 방 대기실 채팅 |
| CHANNEL_ALL | 2 | 인게임 전체 채팅 |
| CHANNEL_WHISPER | 3 | 1:1 귓속말 (미구현) |

채널은 ChatClient 상태에 따라 자동 전환된다 (Lobby → CHANNEL_LOBBY, InSession → CHANNEL_ALL).

### 주요 메시지

Client → Server: `ChatAuth`, `ChatSend`, `ChatHeartbeat`

Server → Client: `ChatAuthResult`, `ChatReceive`, `SystemMessage`, `ChatError`

## ChatClient

### 상태 머신

```
Disconnected → Connecting → Lobby → InSession
     ↑                                   │
     │              GameOver / 로비 복귀   │
     └────────── Disconnect() ────────────┘
     예기치 않은 끊김 → HandleDisconnection (3초 후 재연결 시도)
```

| 상태 | 진입 조건 | 허용 동작 |
|------|-----------|-----------|
| Disconnected | 초기, Disconnect() 호출 | ConnectToChatServer |
| Connecting | ConnectToChatServer 호출 | (대기, 3회 지수 백오프) |
| Lobby | ChatAuth(sessionId="") 성공 | SendMessage(LOBBY) |
| InSession | ChatAuth(sessionId) 성공 | SendMessage(ALL) |

### 연결 시점

- **연결**: `RoomUIController`에서 방 생성(`HandleRoomCreated`) / 입장(`HandleRoomJoined`) 시 `ConnectChatIfNeeded()` 호출
- **해제**: 로비 복귀 시 `RoomUIController.HandleStateChanged(Lobby)` → `chatClient.Disconnect()` / GameOver 시 `HandleGameOver()` → `Disconnect()`

### 세션 재인증

Lobby 진입 시 `SessionReauthPollingLoop` 코루틴 시작 (1초 간격):
1. ECS에서 `RoomAuthState.SessionId` 확정 감지
2. `ChatAuth(sessionId)` 재인증 전송
3. 성공 시 State → InSession

### 이벤트

```csharp
event Action<ChatAuthResult> OnAuthResult;
event Action<ChatReceive> OnMessageReceived;
event Action<SystemMessage> OnSystemMessage;
event Action<ChatError> OnChatError;
event Action OnConnected;
event Action OnDisconnected;
event Action<ChatClientState> OnStateChanged;
```

### 하트비트

10초 간격 `ChatHeartbeat` 전송 (Lobby/InSession 상태에서만).

## ChatUIController

### 패널 표시/숨김

ChatClient가 Lobby 또는 InSession 상태일 때만 패널 표시. 미연결 시 숨김.

### 위치/크기 전환

Inspector에서 설정 가능한 룸/인게임 각각의 position과 size. ChatClient 상태 전환 시 자동 적용.

### 입력 처리

| 키 | 동작 |
|---|------|
| Enter | 비활성 → 활성 (포커스), 활성 → 전송 + 비활성 |
| ESC | 포커스 해제 (전송 없이) |

### 키보드 입력 격리

- `IsChatFocused`: 채팅 입력 중 true → 5개 ECS 입력 시스템에서 키보드 입력 차단 (마우스 유지)
- `WasChatFocusedThisFrame`: ESC로 포커스 해제한 프레임에서 true → ECS가 같은 프레임에 ESC를 이중 처리하는 것 방지

가드 적용 시스템:
- `UnitCommandInputSystem` (A키)
- `StructureCommandInputSystem` (전체 키보드)
- `ConstructionMenuInputSystem` (전체 키보드)
- `CameraSystem` (T키)
- `EntitySelectionSystem` (ESC키)

### 메시지 관리

- 링버퍼: 50개 (초과 시 oldest 제거)
- 새 연결 시 이전 메시지 초기화
- 인게임 세션 진입 시 룸 채팅 이력 초기화
- Rich Text 인젝션 방지: `<` 뒤에 zero-width space 삽입 (`SanitizeRichText`)

### 에러 표시

| 에러 코드 | UI 메시지 |
|----------|-----------|
| RateLimited | 메시지를 너무 빠르게 보내고 있습니다 |
| MessageTooLong | 메시지가 너무 깁니다 |
| PlayerNotFound | 대상을 찾을 수 없습니다 |
| 기타 | `error.Message` 원문 표시 |

## 데이터 흐름

```
유저 입력 (Enter)
  → ChatUIController.TrySendMessage()
  → ChatClient.SendMessage(channel, content)
  → ProtobufFraming.Frame(ChatEnvelope{Send})
  → TCP :8082

Chat Server
  → 브로드캐스트

TCP 수신
  → ChatClient.ReceiveLoopAsync()
  → ProtobufFraming.TryDeframe()
  → DispatchEnvelope()
  → OnMessageReceived 이벤트
  → ChatUIController.AddChatMessage()
  → Instantiate(messagePrefab) + ScrollToBottom
```
